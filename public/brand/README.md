# Brand files

- `logo-source.png`: the official logo as supplied (628x631, white background). Keep it unchanged.
- `logo.png`, `logo-mark.png`, `logo-wordmark.png`: transparent cut-outs generated by
  `scripts/brand/make-logo-assets.py` (also writes `src/app/icon.png` and `apple-icon.png`).

Sampled colours → tokens in `src/app/globals.css`:

| Logo part | Hex | Token |
|---|---|---|
| Cat | `#3690D5` | `--blue-500` (decorative only) |
| Heart | `#03508A` | `--blue-800` |
| Arm / house | `#FFC18D` | `--peach-300` |
| "for" script | `#FF993D` | `--orange-500` |

A vector (SVG) or larger PNG (≥ 1500 px) from the designer would give sharper results on large
screens, the hero poster and Open Graph images.
