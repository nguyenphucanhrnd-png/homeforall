# Image prompts (for the AI image tool)

Use the same STYLE BLOCK and CHARACTER BLOCKS as in `video-shots.md` (copy them here before running).

## 1. Character sheet (do this FIRST, one sheet per character)
```
[STYLE BLOCK, still image] [CHARACTER BLOCK for MIU]
Character reference sheet: five poses of the same clay cat on a plain light-grey seamless background, even soft lighting, no shadows on the background:
front view, three-quarter view, side view, sitting, sleeping curled up. No text, no props.
```
Repeat with the DOG block. Pick the best result per pose; save as `mascots/miu-front.png`, `miu-3q.png`, `miu-side.png`, `miu-sit.png`, `miu-sleep.png`, `dog-front.png`, etc.

## 2. Single mascot for cut-out (parallax layer)
```
[STYLE BLOCK, still image] [CHARACTER BLOCK]
Single full-body clay [cat|dog] sitting, centered, on a plain flat light-grey background (#E8E8E8), soft even lighting,
generous empty margin around the animal so the outline is easy to cut out. No ground shadow, no props, no text.
```
Then remove the background to get a transparent PNG (see README step 4).

## 3. Clean hero poster (optional)
```
[STYLE BLOCK, still image] Clay cottage with orange tiled roof and heart-shaped window on a small green diorama base, warm cream background, no animals, no text.
```
Useful if you want the dog and cat as separate layers on top of the house instead of baked into the video.

## 4. Static fallback illustrations (optional)
The script already makes `poster.webp` and `last.webp` for every clip, which Claude Code uses as static images for reduced-motion and low-end devices. You only need extra illustrations if you want a different look for those cases.

## 5. Decorative icons (optional)
Clay shield, medical cross, syringe, paw print, heart, calendar: single objects on plain grey background, same style, for use as floating badges. Cut out to transparent PNG into `mascots/` (name them `icon-shield.png`, etc.).

## Rules
- No real photos of adoptable pets generated by AI. Real pet photos come only from partners (`real-photos/`).
- Record every AI-generated or stock asset in `CREDITS.md` (tool, date, licence/terms).
